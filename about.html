About This Website

A simple tool for tracking syllabus topics and overall course progress.

What This Website Is

The Course Syllabus Tracking System is a responsive, multi-page website that helps students keep track of what they have covered in class and what they still need to study on their own. It is built to make preparation for midterm tests easier and more organized.

Main Features

  • Create Course: A form to enter the course name, code, teacher, and up to five units with their subtopics.
  • Units Checklist: Each unit lists its topics as checkboxes. Completed topics are crossed out.
  • Progress: A 0% to 100% mastery bar that shows how much of the subject is complete.
  • Responsive Design: The layout adjusts to fit laptops, tablets, and phones.

How to Use It

  1. Open the Create Course page and enter your course details and units.
  2. Go to the Units page and tick each topic as you finish it.
  3. Check the Progress page to see how much of the syllabus is complete.

Technology Used

  • HTML5: Page structure, forms, and checkboxes.
  • CSS3: Styling, grid and flexbox layouts, transitions, and media queries.
  • JavaScript: Handles the Create Course form, saves course data and units, and updates the progress bar when topics are ticked.

Current Limitations

Data is saved in the browser, so it stays on the device and browser where it was entered. Clearing browser data will remove it, and it won't sync across devices. Progress is calculated from the ticked topics, but there are no user accounts or cloud backup yet. A future version could add cloud storage, user accounts, and export options such as PDF.
